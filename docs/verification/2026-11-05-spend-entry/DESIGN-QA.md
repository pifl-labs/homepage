## 화면 역할·정보 위계
홈에서 목적을 이해하고, 정확한 앱 소개 또는 Google Play로 이동한다. 공식 512px 아이콘 → 현재 이름 → 짧은 목적 → Android/광고/선택형 일회성 Pro → 설치 링크 순서다. 가짜 앱 화면을 만들지 않았다. 미리보기가 없을 때만 렌더를 생략하며, 가계부 카드에는 빈 세 번째 열을 예약하지 않는다. 기존 14제품 데이터와 상대 순서는 정확히 보존했다.

## 실제 브라우저 matrix
공식 CUA / IAB, 동일 로컬 빌드. 기본 글자 16px, 200%는 별도 로컬 QA 응답에서 root font-size만 32px로 올린 실제 렌더다. 브라우저 전체 줌이나 사이트의 130% 버튼을 200%로 간주하지 않았다. 이 QA 응답/서버는 배포되지 않는다.

확대 글자 중간 폭은 좁은 320px와 desktop 1280px의 실제 확대 상태로 축소했다. 스타일/레이아웃을 바꾸지 않은 다른 제품의 전체 화면·다른 브라우저·모든 OS는 이번 PASS 범위가 아니다. 모든 측정에서 scrollWidth==viewport, 신규 콘텐츠 자식 가로 넘침0이다. 숫자만으로 PASS하지 않고 원본 화면과 접촉시트로 위계, 문장 단위 줄바꿈, 명암, 카드·버튼 간격을 함께 봤다. 200%에서는 내용이 여러 줄로 흐르며 필수 사실/행동을 숨기지 않는다.

## 수정·실패 보존
초기 아이콘은 작은 동명이미지를 거절하고 SoftwareApplication.image의 512×512 앱 아이콘으로 바로잡았다. 원본 PNG→lossless WebP exact 변환의 모든 RGBA 픽셀이 같다. 초기 일반 WebP 변환은 비교 실패하여 미공개 상태로 보존했다.
초기 홈페이지 샷은 테마 조작 후 스크롤 복원/애니메이션 때문에 카드 밖을 찍은 경우가 있어 카드 시각증거로 쓰지 않았다. DOM 측정과 문서 좌표 기반 native screenshot으로 보완했다. 처음 빈 미리보기 열을 발견한 뒤 #app-pipi-spend만 2열로 수정·재검증했다. 랜딩3개의 HTML과 기존 두 CSS 번들은 이 홈 전용 수정 전후 byte 동일하다. 최대3회 한도 내 UI 수정1회다.

## 기능·일치
세 언어 홈 카드 클릭→각 앱 소개, 기존 개인정보 링크→각 실제 방침 제목·URL, EN→JA 언어 전환에서 동일 앱 경로 유지 확인. 테마 버튼 실제 조작. 기록관은 실제 가계부 선택(aria-pressed=true)과 disclosure open, Android 확인 범위/버전·최초일·iOS 미확인 문장을 표시하고 가짜 과거 사건0개다. 기존41사건/14개 과거 자료를 바꾸지 않았다.
버전·최초 출시일·iOS를 만들지 않음. 법적 문서/앱/설정/스토어/결제/사용자 금융자료 변경·전송0. Play의 공개 제품 설명은 금융 고객 데이터가 아니다.
