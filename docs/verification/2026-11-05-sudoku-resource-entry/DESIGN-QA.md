# DESIGN-QA — 스도쿠 영어 설치 전 체험 진입

**PASS — 영어 스도쿠의 새 종이 체험 카드와 제목 범위.** 자체 검수이며 독립 리뷰/앱 실행/전환 성과 판정이 아니다.

## 목적과 위계
기존 앱 소개에서 공개된 무료 자료를 찾을 수 없던 공백을 메운다. 앱의 기존 힌트 목적을 제목(See where to look next)에 담고, 설치 버튼 아래에서 원본 종이 퍼즐·세 힌트·정답을 먼저 써볼 수 있게 한다. 다운로드를 설치/가입으로 막지 않는다. 기존 자료를 새로 만들거나 업로드하지 않았다. PDF와 전체 텍스트, 영어/2쪽/약7KB 및 앱 내 퍼즐·화면·정확한 힌트 문구가 아니라는 한계를 모두 표시한다.

## 실제 브라우저
공식 CUA IAB에서 동일 빌드의 EN 경로를 light/dark 각각 320·375·768·1280·1920px 기본 글자로 확인했다. 각 테마의320/1280px에서는 로컬 QA 응답에서 root font32px(기본16px의200%)을 실제 렌더했다. 총14개 최종 셀. QA 스타일/서버는 배포하지 않으며 브라우저 전체 줌/사이트130% 버튼과 구분한다. 다른44개 앱 랜딩은 생성 scope ID·HTML 공백만 정규화한 렌더HTML 동등성과 전체시험으로 영향 없음을 확인했다. KO/JA에 영어 체험을 주입하지 않으며 미검증 다른 브라우저·앱/인쇄기·사용자 효과는 PASS 범위가 아니다. 확대 중간폭은 실제320/1280 worst-case로 축소했다.

## 시각·문장·기능
최종 원본 화면과14셀 접촉시트에서 제목→설명→두 행동→한계 정보의 위계, 본문과 버튼 대비, 카드 폭/간격, 좁은 폭과 확대에서 자연스러운 영문 줄바꿈을 확인했다. 카드 본문은 가용 폭을 쓰며 빈 미리보기 열을 만들지 않는다. 9 × 9는 짧은 수학 단위만 묶어 확대에서 의미가 갈라지지 않게 했다. 전체 문장 nowrap/축소/필수 정보 숨김0. 모든 최종셀 scrollWidth==viewport, 신규 자식 넘침0, 버튼 높이>=44px, 수학 단위 한 줄을 별도로 측정했다. 숫자만으로 시각 PASS하지 않았다.
실제 PDF 링크에 키보드 Enter→브라우저 파일 다운로드 성공. 받은6886byte PDF의 전체SHA가 기존 공개본과 같다. 텍스트 링크→실제 원문/Hint3/정답 도착, 뒤로가기·테마 실제 조작 확인. 재다운로드/리소스 발행0, 파일/사용자정보 입력 없음.

## 실패와 보완
초기 밝은 테마 클릭은 클라이언트 초기화 전에 발생해 실제로는 dark였다. 레이블로 성공 처리하지 않고 실제 data-theme/배경 불일치를 발견·보존하고, 실제 light 전환을 확인한 뒤7셀을 보완했다. 수학 표현 수정 뒤 양테마14셀을 같은 조건으로 전부 다시 검수했다. 초기 원시HTML 비교는 새 주석과 빈 슬롯 공백으로45개를 모두 다르게 잡았다. 불필요한 주석을 실제 소스에서 제거하고, 동일 기준/현재 빌드를 실행해 명시한 정규화로 다른44개 동등성을 확인했다. 실패를 skip/정상으로 바꾸지 않았다. 3회 제한 내 시각 수정1회다.
