# 기록관과 홈의 좌우 정렬 — PASS

## 사용자 기준
기록관 내부끼리만 맞추는 것이 아니라, 홈 앱 카드 그리드의 좌우점과 기록관의 필터·구분선·기록·출처 좌우점을 일치시킨다. 별도의 우측 영역을 만들지 않는다.
