# 검증 — 공개 출시 이력 대조

- 16개 앱, 플랫폼별 241건(iOS 128·Android 113), 카드 173개. 같은 버전과 변경을 확인한 68쌍을 묶었다. 기존 49건/40개 카드와 비교해 각각 192건/133개 카드 증가.
- 까치 Android 1.0.0(10/28), 1.1.0 빌드 18(10/30), 1.1.0 빌드 22(10/31)의 별도 게시를 확인했다. 가계부 첫 공개는 Play 스토어 상세의 10/28 표기 대신 실제 배포를 시작한 11/03으로 정정했다.
- 같은 버전이라도 변경이 다른 Android 재배포 및 플랫폼 차이는 분리했다. 심사·테스트와 공개 기록은 섞지 않았다. 게시일은 조회일이나 스토어 등록정보 갱신일로 대체하지 않는다.
- 홈페이지 공개 버전은 그날까지의 최신 스토어 증거에 맞춰 갱신했다. 앱 버전·국가별 스토어 링크·JSON-LD 회귀 검증을 포함한다.
- `npm run build`: 224페이지. `npm test`: 1,028건 통과. `npm run test:built`: 5개 산출물 검사 통과.
- 플랫폼별 접근 범위와 제외 기준은 [coverage.md](coverage.md)에 기록했다. 공개 반영과 readback은 병합 후 별도 확인한다.
