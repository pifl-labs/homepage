# Design QA — PASS (운영 반영 전 빌드)

- Chrome: 한국어·일본어·영어, 320/375/768/1280/1724/1920px, 라이트/다크와 기본/확대 글자(16/32px). 기록관 72개 조합, 홈페이지와 그날 갱신한 앱 3종 288개 조합에서 폭과 잘림을 계측했다.
- 기록관의 홈 컨테이너 정렬 기준과 줄 구분을 유지했다. 우측 영역/사이드바나 CSS 변경은 없다. 제목·설명·플랫폼·날짜·재배포 빌드·펼침 영역을 데스크톱/모바일/확대 글자 캡처에서 검토했다.
- 앱·플랫폼 필터 조합, 다르게 게시된 빌드, 플랫폼을 합친 카드의 각 출시일, 펼침 영역의 출처, 기록 초기화·복귀 흐름을 확인했다.
- 기록관 HTML 및 클라이언트/스타일/공개 데이터 5개 자산을 실제 빌드와 대조했다. 로컬 실행 수치·주요 캡처는 모노레포 동일 날짜 검증 폴더에 보관한다.
