## 사용자 역할과 전후

방문자의 첫 행동은 앱 특징을 이해한 뒤 iOS/Android 스토어로 이동하는 것. 변경 전에는 `무료` 메타·CTA와 위젯 6종 설명이 5개 D-Day/기본 스킨 1종의 무료 한도, 추가 스킨·광고·일회성 구매를 분명히 드러내지 않았다. 한국어 공개 랜딩의 네트워크 설명도 광고만 언급해 구매 통신을 빠뜨렸다.

변경 후에는 스토어 배지 **바로 아래**에 3개 언어 모두 `5개 D-Day + 기본 스킨 1종 무료 / 일회성 Pro로 무제한·추가 스킨 5종·광고 제거`를 설명한다. 캡처 설명에서도 추가 스킨의 Pro 조건을 밝히고, 기기 저장 기능 설명에서 광고·인앱결제 네트워크를 구분했다. CTA 자체는 `무료로 시작`이므로 유료 기능까지 무료라는 인상을 주지 않는다.
